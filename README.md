# 🇺🇸 RPM WEST

**RPM WEST** — Telegram RolePlay-проект в сеттинге США. Игровой бот написан на Python; данные игроков и игровых систем хранятся в SQLite. В проект также встроен веб-интерфейс Telegram Mini App.

> Проект находится в разработке. Набор игровых систем и их поведение могут меняться между версиями.

## Основные компоненты

- Telegram-бот на **aiogram 3**.
- Игровые профили, фракции, должности и внутриигровые активности.
- Фракционные процессы, поручения и чек-листы.
- NPC и диалоги; для AI-функций можно подключить OpenRouter.
- Telegram Mini App и HTTP API на **aiohttp**.
- SQLite для хранения игрового состояния.

## Требования

- Python 3.11 или совместимая версия Python 3.
- Telegram bot token от [@BotFather](https://t.me/BotFather).
- Числовой Telegram ID хотя бы одного администратора.
- Для AI-диалогов NPC — API-ключ OpenRouter (необязательно).

## Локальный запуск

1. Склонируйте репозиторий:

   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd RPM-WEST
   ```

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   # Linux/macOS:
   source .venv/bin/activate
   # Windows PowerShell:
   # .venv\\Scripts\\Activate.ps1
   pip install -r requirements.txt
   ```

3. Создайте `.env` на основе `.env.example` и заполните значения. Не публикуйте `.env`.

4. Запустите бота:

   ```bash
   python RPM_WEST_UPDATED.py
   ```

Приложение читает настройки из переменных окружения. Сам файл `.env` автоматически не загружается: при локальном запуске переменные нужно экспортировать в оболочке или использовать менеджер переменных окружения вашей IDE/хостинга.

## Переменные окружения

| Переменная | Обязательность | Назначение |
|---|---|---|
| `BOT_TOKEN` | Обязательно | Токен Telegram-бота |
| `ADMIN_IDS` | Обязательно для администрирования | Числовые Telegram ID через запятую, например `123456789,987654321` |
| `OPENROUTER_API_KEY` | Необязательно | Ключ OpenRouter для AI-функций NPC |
| `NPC_AI_MODEL` | Необязательно | Модель OpenRouter; по умолчанию `openrouter/free` |
| `RPM_WEST_MINI_APP_URL` | Необязательно | Публичный HTTPS-адрес Mini App |
| `RPM_WEST_DATA_DIR` | Рекомендуется на хостинге | Каталог для SQLite и резервных копий; на Railway используйте `/data` при подключённом Volume |
| `PORT` | Задаётся платформой | Порт HTTP API Mini App; код читает эту переменную автоматически |
| `RPM_WEST_WEB_HOST` | Необязательно | Адрес привязки HTTP API; по умолчанию `0.0.0.0` |

## Развёртывание на Railway

1. Создайте Railway Project и подключите этот GitHub-репозиторий как сервис.
2. Установите Start Command: `python RPM_WEST_UPDATED.py`.
3. Добавьте переменные `BOT_TOKEN` и `ADMIN_IDS`. При необходимости добавьте `OPENROUTER_API_KEY` и `NPC_AI_MODEL`.
4. Подключите **Persistent Volume** к сервису с mount path `/data` и задайте `RPM_WEST_DATA_DIR=/data`. Без постоянного хранилища SQLite-файл может исчезнуть при пересоздании контейнера.
5. Сгенерируйте публичный домен Railway. Убедитесь, что сервис принимает HTTP-трафик на переменной `PORT`, затем укажите полученный HTTPS-адрес в `RPM_WEST_MINI_APP_URL`.
6. После деплоя проверьте логи запуска, работу Telegram polling и открытие Mini App из Telegram.

Бот и Mini App API запускаются одним Python-процессом: бот использует Telegram polling, а HTTP API слушает `0.0.0.0:$PORT`.

## Данные и безопасность

- Не добавляйте в GitHub токен бота, API-ключи, `.env`, базу SQLite или резервные копии.
- `.gitignore` исключает эти файлы из обычного добавления в Git, но не удаляет секреты, уже попавшие в историю коммитов.
- Если токен или ключ когда-либо публиковался, отзовите/перевыпустите его у соответствующего провайдера.
- Храните SQLite на Persistent Volume и периодически проверяйте резервные копии.
- Не запускайте одновременно несколько экземпляров бота, использующих одну и ту же SQLite-базу.
